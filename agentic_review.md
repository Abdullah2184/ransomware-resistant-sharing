## 2. Component Map & Intended Deployment Placement

A key concern raised in `manual_review.md` (#5, #7, #10) is why logic is split between `crates/` and `services/` and where each folder runs in production.

**Why `crates/` vs `services/` exists:**
- `crates/` holds **reusable Rust libraries** (domain types, cryptographic primitives, port traits, and protocol adapters) that are compiled into one or more binaries without creating dependency cycles (`TECHNICAL_SPECIFICATION.md` §§11–12).
- `apps/` holds **endpoint-facing user binaries** (currently `apps/cli`; future `apps/desktop`).
- `services/` holds **independently deployed server binaries** (`services/gateway`, `services/indexer`).
- `contracts/` holds **on-chain EVM smart contracts** and Hardhat tests/deployment modules.
- `infra/` holds **infrastructure orchestration** (Besu QBFT, Kubo/IPFS Cluster, PostgreSQL).

### Deployment Note on Indexing Placement (`manual_review.md` #11)

`manual_review.md` asks whether indexing can run on the user endpoint to reduce gateway latency. Based on `TECHNICAL_SPECIFICATION.md` §§2, 4, 7.6, 7.12, and 10.4.7:
- **Recommendation: keep canonical event indexing on the organization server (`services/indexer` + PostgreSQL), and optionally add a non-authoritative client-side cache with `finalizedBlock` cursors if UI browsing latency becomes noticeable.**
- **Reasons:**
  1. **Trust & network boundary:** Endpoint-side indexing requires exposing Besu JSON-RPC (`eth_getLogs`) directly to untrusted endpoints, breaking §4/§7.6 where endpoints talk only to the authenticated gateway over HTTPS.
  2. **Consortium metadata exposure:** Full chain-log syncing would pull all organizations' on-chain file/folder/ACL events onto every endpoint.
  3. **Operational overhead:** Each endpoint would have to maintain a persistent database, handle chain checkpoints, and pay cold-start sync latency.
  4. **Latency profile:** Gateway-served SQL queries against a co-located organization PostgreSQL projection are sub-millisecond and already avoid QBFT/RPC round trips for browsing/history.

## 3. Strengths & Gaps Against `TECHNICAL_SPECIFICATION.md`

### Strengths
- **Cryptography core (`crates/crypto`):** Clean, zeroizing AES-256-GCM chunk encryptor/decryptor with non-reusable `prefix64-index32` nonces and full context-bound AAD (`fileId`, `versionNumber`, `epochId`, `chunkIndex`, `totalChunks`). RFC 9180 HPKE (`X25519` + `HKDF-SHA256` + `AES-256-GCM`) with context binding. Strict canonical JSON codecs + JSON Schemas for manifests (`schemas/encrypted-file-manifest-v1.json`) and envelope sets (`schemas/key-envelope-set-v1.json`, max 1,024 sorted unique members).
- **Cross-language EIP-712 parity:** Rust (`crates/crypto`, `services/gateway`), Solidity (`RrdsEip712.sol`), and TypeScript (`viem` in `contracts/test/Eip712.ts`) all match shared deterministic digest fixtures in `tests/fixtures/eip712-v1.json`.
- **Smart contract separation & governance design:** Clean split between `AccessGovernance.sol` and `FileRegistry.sol`, atomic file creation + initial creator Read/Write ACL + initial envelope pointer, version-scoped historical Read ACL with revocation epoch invalidation, signing-key EIP-712 proof-of-possession, immutable folder parents, and `RrdsTimelockController` (24-hour delay, open executor, no deployer admin bypass). `AccessGovernance` bytecode (17,229 bytes) stays well under EIP-170 (24,576 bytes).
- **Fail-closed read audit & QBFT finality alignment:** Gateway access lookup and content retrieval query a single recorded QBFT-committed block number (`latest` head, not PoS `finalized`) and commit an append-only Keccak-256 hash-chained PostgreSQL audit row before returning CIDs or streaming ciphertext.

### Major Gaps Against Specification (Re-verified 27 November 2026)
1. **Application core (`crates/application`):** **Resolved & hardened** — `AuthService`, `UploadService` (create/modify/append-only restore + `PreUploadScanner` + `OrphanedUpload`), `DownloadService` (signed lookup + envelope CID/manifest/chunk AEAD verification), and `ShareService` (envelope-set update without ciphertext re-encryption, duplicate-share rejection) are implemented strictly on port traits with 8 unit tests + cross-component/live-IPFS tests.
2. **Transaction relayer (`chain_adapter` + `services/gateway`):** **Resolved & documented** — Type-2 zero-gas-price RLP tx signing, sequential nonce tracking, `Committed`/`Reverted`/`ConfirmationTimedOut` receipt tracking, `reconcile_transaction`, and `RelayerStartupPolicy` guard are implemented and documented in [`docs/adr/chain-adapter-rpc-and-relayer.md`](docs/adr/chain-adapter-rpc-and-relayer.md).
3. **Gateway API endpoints (§8.1):** **Resolved & refactored** — `GET /v1/files`, `POST /v1/files`, `POST /v1/files/{fileId}/versions`, `GET /v1/files/{fileId}/versions`, `GET /v1/files/{fileId}/versions/{version}/envelope`, `POST /v1/files/{fileId}/versions/{version}/envelopes`, `POST /v1/blobs/content`, `POST /v1/blobs/envelopes`, `DELETE /v1/auth/session`, and `GET /v1/audit` are all implemented; monolithic 7,824-line `routes.rs` was refactored into 6 cohesive modules under `services/gateway/src/routes/` (`mod.rs`, `middleware.rs`, `auth.rs`, `reads.rs`, `writes.rs`, `blobs.rs`) with shared `authorize_version_read`, `authenticate_active_member`, `read_bounded_envelope_set`, and `WriteAuditContext` helpers and zero `#[allow(clippy::too_many_arguments)]` suppressions. Multi-sig ACL/governance proposals remain intentionally Safe/Timelock-governed per [`docs/adr/gateway-authentication-and-audit.md`](docs/adr/gateway-authentication-and-audit.md).
4. **Gateway hardening (§8, §10.4.6, §14):** **Resolved for local MVP** — independent source (`src:*`), per-member (`member:*`), and invalid-signature (`invalid_sig_src:*`) PostgreSQL rate-limit buckets, transactional session revocation, `X-Request-Id` correlation headers, structured JSON operational logs, and least-privilege PostgreSQL role separation ([`infra/postgres/init-roles.sql`](infra/postgres/init-roles.sql)) are implemented and live-verified. Reverse-proxy TLS termination remains an explicit deployment/production boundary (documented in `services/gateway/README.md` and enforced by default in `apps/cli` for non-loopback URLs).
5. **CLI (`apps/cli`):** **Resolved & hardened** — 13 thin commands (`health`, `login`, `logout`, `whoami`, `identity`, `ls`, `history`, `upload`, `modify`, `download`, `share`, `restore`, `audit`) calling `crates/application` and `GatewayHttpClient` over HTTPS (redirect-disabled, bounded responses, `Zeroizing` bounded file reads, atomic `0600` writes, zero direct DB/Besu/IPFS dependencies). Uses zero-dependency manual argument parsing to keep offline `--locked` builds lean without adding `clap`.
6. **Key custody production guard & hardware adapter (`crates/key_custody`):** **Guard resolved** (`CustodyStartupPolicy` + `verify_provider_policy` rejecting `test_only` / exportable providers and zero/reused key material); PKCS#11/HSM adapter remains post-MVP (§17 #1).
7. **Scanner (`crates/scanner`):** **Resolved** — `PreUploadScanner`, `ScannerMode` (`Disabled` default), `DisabledScanner`, and fail-closed CLI `RRDS_SCANNER_MODE` parsing wired into `UploadService`.
8. **Schemas & fixtures (§11, §15.1):** **Resolved** — `schemas/access-request-v1.json`, `schemas/version-manifest-v1.json`, and RFC 9180 / OpenSSL HPKE cross-implementation vectors (`tests/fixtures/hpke-rfc9180-v1.json`) added and verified in `rrds-tests`.
9. **Deployment & End-to-End Acceptance (§15.3–§15.4):** **Offline & local infra verified; live Besu P6 activation pending 24h timelock** — `tests/{integration,end_to_end,security}/` populated, PostgreSQL (`rrfs_indexer_test`) & 2-peer Kubo/Cluster live-verified, contracts deployed on local Besu with 24h timelock ready `2026-11-27T20:26:20.000Z`.

## 4. Concrete Issues, Bugs, Risks & Duplication Findings (Re-verified 27 November 2026)

### Bugs & Security Issues Found in Initial Audit — All 10 Resolved
1. **[HIGH — Security] Un-rate-limited `POST /v1/files/{file_id}/versions/{version}/access` route:** **Resolved** — `rate_limit_action` in `services/gateway/src/routes/middleware.rs` covers all 16 API routes (`file.access` included), verified by `rate_limit_covers_all_protected_and_public_api_routes` and live Axum 429 tests.
2. **[MEDIUM — Correctness] Indexer projects initial envelope-set revision as `0` instead of `1`:** **Resolved** — `services/indexer/src/main.rs` inserts `revision = 1` on `EnvelopeSetInitialized`, explicitly asserted against live PostgreSQL in `event_replay_is_idempotent_and_projection_rebuild_is_atomic`.
3. **[MEDIUM — Correctness / Security Consistency] Indexer does not clear historical read grants on `ReadAccessRevoked`:** **Resolved** — `services/indexer/src/main.rs` invalidates matching `historical_read_access_projection` rows on `ReadAccessRevoked`, live-verified in `read_revocation_invalidates_historical_grants_and_reindex_reset_clears_state`.
4. **[MEDIUM — Broken Dormant Test] Indexer DB test omits `"0x"` prefix on hex data:** **Resolved** — fixed `"0x"` prefix and added explicit live PostgreSQL assertion on `reconcile_head` upserting a `0x`-prefixed `files_projection` row.
5. **[LOW — Defense-in-Depth] Fail-open fallback in `access_lookup` key version check:** **Resolved** — `authorize_version_read` strictly checks `signer != member.signing_address || key_version.get() != member.encryption_key_version`.
6. **[LOW — Diagnostics] Copy-pasted error messages in gateway config:** **Resolved** — `parse_address` parameterized with env var name and unit-tested.
7. **[LOW — Redundant check] Duplicate condition in `FileRegistry.sol`:** **Resolved (27 Nov 2026)** — removed duplicate `files[folderId].status != FileStatus.Unregistered` guard in `contracts/contracts/FileRegistry.sol:244`, recompiled with cached `solc 0.8.34`, and verified `35 passing (29 solidity, 6 nodejs)`.
8. **[MEDIUM — Missing ADR / Spec Deviation] Hand-rolled JSON-RPC & ABI instead of Alloy:** **Resolved** — formally documented and justified in [`docs/adr/chain-adapter-rpc-and-relayer.md`](docs/adr/chain-adapter-rpc-and-relayer.md).
9. **[LOW — Partial Spec Feature] Private metadata (chunk 0) encrypt/decrypt missing:** **Resolved** — `encrypt_private_metadata` / `decrypt_private_metadata` with `MAX_PRIVATE_METADATA_BYTES = 64 KiB` implemented in `crates/crypto` and wired through `crates/application`.
10. **[LOW — Operational] `IpfsClusterStore::put_content` does not fail over across configured Kubo nodes on upload:** **Resolved** — `crates/ipfs_adapter` supports multi-Kubo and multi-Cluster failover on both upload and retrieval, unit-tested and live-verified across 2 running peers.

### Duplication & Interdependency Observations (`manual_review.md` #8)
- **EIP-712, keccak, and hex encoding duplication:** **Resolved (27 Nov 2026)** — `LoginChallengeDigestInput` & `keccak256` live canonically in `crates/crypto`, and shared zero-dependency hex codecs (`encode_hex`, `encode_prefixed_hex`, `decode_prefixed_hex`, `parse_fixed_hex`, `parse_lowercase_fixed_hex`) live canonically in `crates/domain/src/hex.rs` and are reused across `apps/cli`, `crates/crypto`, `crates/chain_adapter`, `services/gateway`, and `services/indexer`.
- **Gateway port abstraction & route modularity:** **Resolved (27 Nov 2026)** — `GatewayChainPort`, `GatewayStorePort`, and `GatewayRelayerPort` abstract all external dependencies, and `services/gateway/src/routes/` is cleanly split into `mod.rs`, `middleware.rs`, `auth.rs`, `reads.rs`, `writes.rs`, `blobs.rs`, and `tests.rs` with shared authorization/envelope helpers (including active-member defense-in-depth on `file_version_history`).
- **Service SQL ownership vs `crates/metadata_store`:** **Intentional boundary** — `crates/metadata_store` owns connection pooling (`PostgresPoolConfig`), versioned SQLx migrations (`0001`–`0006`), and `MigrationMode` (`verify` default), while `services/gateway/src/store.rs` and `services/indexer/src/main.rs` own their role-scoped SQL queries matching the `rrfs_gateway` vs `rrfs_indexer` trust boundary.
- **Documentation & infrastructure drift:** **Resolved (27 Nov 2026)** — removed Hardhat `Counter` template files, empty `crates/metadata_store/src/migrations/`, empty `docs/source/`, and unused root `package.json`; fixed stale `docs/api.md` wording (both line 71 QBFT head and line 138 historical sharing/download status); synchronized `README.md`, `infra/ipfs-cluster/README.md`, and component READMEs.
